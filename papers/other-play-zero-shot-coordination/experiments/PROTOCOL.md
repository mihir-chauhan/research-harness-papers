# Protocol
Tasks: lever, safe, signal (see BRIEF.md). Systems: SP, OP, PBT (population, K=8), ablation OP-full. Seeds 0-4; each seed trains 20 independent agents/populations with a seed-specific generator; the run metrics are exact over all 380 ordered pairs. No train/test split: games are fixed; evaluation is exact expected payoff of fully trained policies. Hyperparameters fixed a priori (1500 steps, batch 64, lr 0.05, init sd 1) and identical for all systems (PBT uses the same budget in each stage, so it uses 2x environment samples plus K x the SP agents). Tuning budget: none on cross-play; one OP lever smoke test at seed 99 (6 configs, not logged in the registry) informed the sweep ranges. Hardware: CPU, 2 threads, shared Mac. Run durations 3-200 s (registry), about 51 min in total, which exceeded the nominal 30 min budget. Streams are shared: SP/OP use the same initial logits per seed; the steps sweep is one trajectory per seed observed at four lengths; the init sweep rescales the same draws. Registry note: the registry was de-duplicated by hand after an overlapping interrupted driver; for three kept rows the log file is the other duplicate's (payoff metrics identical, runtime differs).
Groups: main, abl_symmetry (OP vs OP-full), sweep_popsize (K in 1,2,4,8,16,32), sweep_init (init sd for SP and OP, lever), sweep_steps (OP steps, lever).
