\textbf{Hypotheses.} \textbf{H1}: SP reaches near-perfect self-play but much lower cross-play on all tasks. \textbf{H2}: OP has higher cross-play than SP on every task. \textbf{H3}: Population cross-play exceeds SP, stays below OP, and grows with population size $K$. \textbf{H4}: OP needs the correct symmetry group (OP-full loses the advantage in the lever game).

\textbf{Protocol.} Each \emph{run} is one (system, task, seed) triple that trains 20 independent agents (or 20 independent populations of $K=8$) with a seed-specific generator and evaluates all 380 ordered pairs exactly; seeds $0$--$4$ (five seeds per cell). The games are fixed, so there is no data split: evaluation is the exact expected payoff of the trained policies. Hyperparameters (1500 steps, batch 64, Adam 0.05, init std 1) were fixed a priori and are identical for every system; there was no tuning on cross-play, apart from a small OP lever smoke test (6 configurations, seed 99, not logged in the run registry) that informed the ranges of the sweeps in Section~\ref{sec:ablations}. Note that the population method uses twice the updates per evaluated agent and $K$ extra SP agents. Hardware is a shared CPU Mac with 2 threads; in-script runtimes in the registry range from \rhval{abl_symmetry/self-play/safe/runtime_s/min:1} s (an SP run on the safe game) to \rhval{sweep_popsize/population-fcp-style@pop_size=4/signal/runtime_s/max:1} s (a signal-game population-sweep run; the longest are the $K=32$ populations, the 15000-update OP runs and the signal-game population sweeps), and the summed run durations exceeded the nominal 30-minute budget (\texttt{rh budget} reports the total). Runtimes are wall-clock measurements and, unlike the payoff metrics, do not reproduce to the digit. Random streams are shared by design: each (task, seed) uses one generator, so SP and OP start from the same initial logits; the training-length sweep observes one trajectory per seed at four lengths (runs are not independent replications); the initial-scale sweep rescales the same normal draws; and the $K=1$ population's stage-1 agents are the SP agents. Statistics are Welch $t$-tests and Cohen's $d$ over seeds, as reported by \texttt{rh compare}; with five seeds per cell they are low-powered, and no multiple-comparison correction is applied. Code: \texttt{method/run.py}; the driver is \texttt{experiments/run\_all.sh}.

\textbf{Registry note.} An interrupted earlier driver and the resumed one overlapped for part of the main group, so some (system, task, seed) cells were logged twice in the registry with deterministic, identical seeds; duplicates were removed (first entry kept) before aggregation. The symmetry-ablation group re-runs the SP and OP configurations of the main group so that every ablation table is self-contained; these are not additional independent evidence.
