\textbf{Everything is simulated.} Tasks are named \texttt{L\{L\}\_A\{A\}\_K\{K\}}. The main grid has $(L,A)\in\{(15,4),(20,20)\}$ and $K\in\{0,1,2,4\}$ (eight tasks; $K=3$ and other $(L,A)$ pairs were not run, so $L$ and $A$ are confounded). Each seed (0--4) draws a new landscape and new data; all systems see the same landscape and data for a given (task, seed), so comparisons are paired. In the main group the training set has $N=1000$ uniformly random sequences with noiseless fitness; the test set is 5000 other uniformly random sequences. Random sequences are far from each other (Hamming distance about $L(1-1/A)$), so this is an interpolation-without-neighbours test, not an extrapolation test.

\paragraph{Endpoints.} Test Spearman correlation, \emph{design\_hit} and \emph{design\_gain} as defined in Sec.~\ref{sec:method}; with $b=10$ proposals design\_hit takes values in multiples of $0.1$ per run. We also log the fraction of all single mutants that beat the parent (\emph{frac\_mutants\_better}), which is the exact expected hit rate of random proposals and is reported as ``Chance'' in Table~\ref{tab:main}, and fit time. \emph{design\_gain} is logged in the registry but not analysed in this paper.

\paragraph{Further groups.} \emph{sweep\_n}: $N\in\{250,500,2000,4000\}$ on L15\_A4\_K2 and L20\_A20\_K1 for the four learned systems (5 seeds, where the proposal had planned 3; $N=1000$ from the main group). \emph{abl\_pair}: the two pairwise-ridge ablations on the eight main tasks (5 seeds).

\paragraph{Tuning and compute.} All hyperparameters are selected inside each run on training data only (Sec.~\ref{sec:method}); the test set is used only for reporting; nothing was tuned across tasks. Hardware: a shared CPU laptop, 2 threads per run, two runs in parallel; according to the run registry the longest of the 440 runs took about 22 s and the registry spans about 14 minutes of wall-clock. Code, protocol and the run registry are in the repository (\texttt{method/run.py}, \texttt{experiments/PROTOCOL.md}). With five seeds the smallest attainable one-sided Wilcoxon $p$ is $1/32\approx0.031$; we report effect sizes and seed spreads, and treat all $p$-values (paired $t$-tests from \texttt{rh compare}; Wilcoxon tests and rank correlations from \texttt{analysis/hyp.py}) as indicative.
