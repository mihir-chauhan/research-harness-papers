\textbf{Tasks.} \emph{digits}: scikit-learn digits (1797 images, 64 features scaled to $[0,1]$), a seed-dependent random split into 600 train, 300 validation and 897 test images. Symmetric label noise $\eta\in\{0,0.2,0.4\}$ is applied to train and validation labels; test labels are clean. \emph{spirals}: a two-class, 1.5-turn spiral with Gaussian input noise, 400/200/400 train/val/test points from the same generator, $\eta=0.2$. Task names are \texttt{digits\_n}$\eta$ and \texttt{spirals\_n0.2}.

\textbf{Training.} All systems (including the ablations): momentum 0.9, base learning rate 0.1 with cosine decay to 0, batch 100, 150 epochs (900 steps for digits), final-epoch model, no early stopping, no augmentation. The budget is matched in epochs, not in gradient evaluations: SAM and its ablations use two per step. The learning rate was set once from a smoke test on SGD and not tuned per system (Sec.~\ref{sec:limitations}). The code is the same for all systems (\texttt{method/run.py}); the sharpness is measured with identical settings for all.

\textbf{Hyper-parameter selection.} For each task, SAM's $\rho\in\{0.02,0.05,0.1,0.2,0.5,1.0\}$ (6 values) and SGD+WD's $\lambda\in\{10^{-4},10^{-3},10^{-2},5\cdot10^{-2}\}$ (4 values) were evaluated on three tuning seeds (100--102, \rhval{count/tune/runs} runs) and the value with the highest mean \emph{noisy} validation accuracy was chosen (Table~\ref{tab:sel}). The tuning seeds differ from the evaluation seeds, but on digits every seed re-splits the same pool of 1797 images, so the tuning train/validation images overlap the test images of the evaluation seeds: the selection data are not disjoint from the evaluation test data (the spirals data are freshly generated per seed). This applies equally to SAM and SGD+WD. Plain SGD has nothing to tune. The ablation SAM+WD simply reuses both selected values and was not tuned jointly.

\textbf{Evaluation.} Seeds 0--4 (5 seeds; the seed fixes the split, noise, initialisation and batch order, so seeds are paired across systems). The main group has \rhval{count/main/runs} runs; $\rho$ and $\lambda$ sweeps reuse the evaluation seeds with the non-selected values (\rhval{count/sweep_rho/runs} and \rhval{count/sweep_wd/runs} runs; the selected value comes from the main group), and the ablation group has \rhval{count/abl_sam/runs} runs. Statistical tests are Welch and paired $t$-tests on the 5 per-seed test accuracies (\texttt{rh compare}); with $n=5$ they have little power. The registered tests are uncorrected; Table~\ref{tab:cmp} also lists Holm-adjusted paired $p$-values over its 8 comparisons. The Spearman correlations, the Holm-adjusted $p$-values and the per-seed differences are computed from the logged runs by \texttt{experiments/derive.py} and logged as \rhval{count/derived/runs} analysis rows (group \texttt{derived}) of the run registry.

\textbf{Compute.} Apple M1 Pro CPU, 2 threads, PyTorch, on a shared machine. In the main group a digits run at 20\% noise takes on average \rhval{main/sgd/digits_n0.2/runtime_s/mean:1}\,s for SGD and \rhval{main/sam/digits_n0.2/runtime_s/mean:1}\,s for SAM, which makes two gradient evaluations per step; these are wall-clock times and, unlike the result metrics, they do not reproduce to the digit when a run is repeated. Code, logs and the run registry are in the repository.
