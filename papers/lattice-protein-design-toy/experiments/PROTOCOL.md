# Protocol
Task hp16 (N=16, 802,075 conformations, 456 conformations with a uniquely-folding sequence, 1,539 such sequences). Targets = those 456. Global DEV = 20% of chain-reversal classes (tuning only). Per seed s in 0..4: remaining classes shuffled by s, 25% -> test targets (91 for seed 0), 75% -> training conformations. All systems use identical test targets per seed. Metrics: succ_k = fraction of test targets for which the best of K candidates folds uniquely to the target. Tuning budget: SA 9 configs, AR 4 configs (DEV, seed 100). Hardware: shared CPU machine, 2 threads per process. Runs: experiments/run_all.sh.
