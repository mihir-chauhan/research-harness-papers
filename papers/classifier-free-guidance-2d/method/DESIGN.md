# Design
`method/run.py`: data sampler, MLP eps-network (2+32 time+32 class embedding -> 3x128 SiLU -> 2), cosine-schedule DDPM T=100, label dropout p (null token index 4), 5000 Adam steps (lr 2e-3 cosine decay, batch 512), ancestral sampler with CFG (w), temperature (tau scales x_T and injected noise), optional guidance interval [lo,hi] on t/T, x0 clip +-3 (normalised by data scale 3). Metrics as in BRIEF.md, averaged over 4 classes x 1500 samples. `--real` evaluates fresh true samples as a reference row. The trained net is cached per (task, seed, p, steps) so all sampling configs of a seed share one network.
