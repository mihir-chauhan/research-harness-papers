\textbf{Tasks.} \texttt{mix\_overlap} ($\sigma=0.6$; neighbouring modes of different classes are $2R\sin(\pi/12)/\sigma$ standard deviations apart, so classes overlap and real samples have class accuracy below 1) and \texttt{mix\_sep} ($\sigma=0.35$, same layout, classes nearly disjoint). The layout, weights and $R$ are fixed; there is no train/test split because training data are streamed fresh from the generator and evaluation uses newly sampled model outputs and fresh reference points.

\textbf{Training.} MLP with a sinusoidal time embedding with 8 frequencies (16 sin/cos features) (to 32 units), a 32-unit class embedding table with a null token, three hidden layers of 128 SiLU units; Adam, lr $2\times10^{-3}$ with cosine decay, 5000 steps, batch 512, label dropout $0.1$ (ablated in Table~\ref{tab:abl}); data scaled by $1/3$. One network per (task, seed, $p$), seeds 0--4, cached and shared by all sampling configurations of that seed, so all compared systems differ only in sampling. Training takes about 50\,s.

\textbf{Evaluation.} 1500 samples for each of the 4 classes (6000 per run), 100 ancestral steps, same $x_0$ clipping and noise generator seed for every system; metrics as defined above, averaged over classes. Tables report means over five seeds; $\pm$ is the sample standard deviation across seeds. Hypothesis tests are the paired $t$-tests over seeds registered in \texttt{proposal.md} (Welch for H4, whose two tasks share seeds), at $\alpha=0.05$, uncorrected for the six tests.

\textbf{Grids.} Guidance $w\in\{0,0.5,1,2,3,5,8\}$ and temperature $\tau\in\{1,0.8,0.7,0.5,0.4,0.3,0.2\}$ on \texttt{mix\_overlap}; on \texttt{mix\_sep} only $w\in\{0,3,8\}$ and $\tau\in\{1,0.5\}$. Grids were fixed before the runs; no hyperparameter was tuned on the evaluation metrics (no tuning budget); the only change after a first timing trial on seed 0 was reducing the network from 192 to 128 hidden units and training from 8000 to 5000 steps to fit the CPU budget. The main method is CFG with $w=3$, picked in advance as a typical value, not tuned.

\textbf{Compute.} CPU only (2 threads, shared machine); each run $\le$55\,s, 120 registry runs (110 grid runs plus 10 real-sample reference runs) in about 21 minutes in total, plus 20 per-mode runs. Twenty additional registry rows with status \texttt{failed} come from a shell quoting error when launching the per-mode runs; they have no metrics, and the runs were repeated correctly.
