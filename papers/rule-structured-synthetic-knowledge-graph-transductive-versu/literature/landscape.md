# Landscape

- Embedding models (TransE [Bordes2013TranslatingEF], DistMult [yang2014embedding], ComplEx [trouillon2016complex], RotatE [sun2019rotate], ConvE [dettmers2017convolutional]) learn one free vector per training entity; they are transductive: a new entity has no trained vector. Tuned versions of these models are strong on standard benchmarks [rossi2020knowledge]; PyKEEN [ali2020pykeen] ships tiny datasets (Kinships, UMLS) that are rule-rich.
- Rule learners (Neural-LP [yang2017differentiable], DRUM [sadeghian2019drum]) learn weighted chains of relations and are inductive by construction.
- Subgraph / path GNNs: GraIL [teru2019inductive] (enclosing subgraph, disjoint train/test entities), NBFNet [zhu2021neural] (query-conditioned Bellman-Ford message passing), relational message passing (PathCon, [2002.06757 key in refs.bib]), RMPI, ULTRA [galkin2023foundation]; R-GCN [schlichtkrull2017modeling] mixes entity-specific parameters with message passing. An open challenge for inductive link prediction is documented by [galkin2022open].
- Closest work: GraIL-style inductive splits derived from existing benchmarks; they do not control the generative rules, so the share of test triples that is rule-inferable is unknown.
- Gap: a fully rule-generated graph pair (train world, fresh world), where the ceiling is known by construction, lets us measure per relation how much an embedding model loses when entities are new, how much fold-in recovers, and what depth/sparsity a path model needs. We make no claim of a new method: Path-MP is a reduced NBFNet-style model.
