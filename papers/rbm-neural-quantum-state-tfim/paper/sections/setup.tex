\textbf{Tasks.} $N=10$ with $\Gamma\in\{0.25,0.5,0.75,1,1.25,1.5,2\}$ and $N\in\{8,12\}$ with $\Gamma\in\{0.5,1,1.5\}$: 13 tasks, $J=1$, written $N/\Gamma$ below. \textbf{Systems.} \{MF, Jastrow, RBM $\alpha=1,2,4$\}$\times$\{SGD, SR\}: 10 systems, all reimplemented in \texttt{method/run.py}; the method of record is RBM $\alpha{=}2$ with SR, the rest are baselines. \textbf{Seeds.} Main runs use seeds 0--4 and both starts ($13\times10\times5\times2=$ \rhval{const/main_runs} runs); the seed fixes the initial parameters and the sampler. Tuning uses disjoint seeds 100--102.

\textbf{Budget.} Every system and start gets \rhval{const/iterations} iterations with 256 samples per iteration (10$N$ burn-in steps, $N$ Metropolis steps between iterations) and SR shift $\epsilon=10^{-2}$. The learning rate is the only tuned quantity, per (ansatz, optimiser), from the grid $\{0.003,0.01,0.03,0.1\}$ for SGD and $\{0.02,0.05,0.1\}$ for SR, by the lowest mean $\epsilon_E$ over 3 tasks (10/0.25, 10/1, 12/0.5) and 3 tuning seeds from start S, a diverged run counting as infinite error. The SGD grid has one more point, so tuning cost differs by optimiser (Table~\ref{tab:check}). Selected rates: 0.1 for MF (both optimisers) and RBM $\alpha{=}2,4$ with SR; 0.05 for RBM $\alpha{=}1$ with SR; 0.03 for Jastrow and all RBMs with SGD; 0.02 for Jastrow with SR. Rates were not re-tuned for start B.

\textbf{Protocol history.} Two earlier protocols (v1: rate tuned on one task and one seed; v2: 3 tasks, one seed) are superseded rows in the registry (Table~\ref{tab:check}). An audit of the single-start results found two faults, both fixed here: Jastrow was stored as an $N{\times}N$ block with only the upper triangle used (it now has one parameter per pair; all Jastrow runs were repeated), and from start S the baselines were stuck in poor states at small fields. Start B and the two-start selection were therefore added for all ten systems, after the hypotheses were registered.

\textbf{Reporting.} Unless a start is named, table cells are medians over the 5 seeds of the selected state. The selected runs are listed again, unchanged, in the registry group \texttt{selected} (\texttt{experiments/list\_selected.py}); the ratios and paired tests of the selected states are those of \texttt{rh compare} on that group. A run is ``diverged'' if its parameters became non-finite. Hardware: shared CPU, 2 threads, numpy. Run counts per group and run times are in Table~\ref{tab:check}; the brief's target of about 30 minutes for all experiments was exceeded. Code, logs and the run registry are in the repository; \texttt{experiments/make\_tables.py} builds all tables and figures from the registry.
