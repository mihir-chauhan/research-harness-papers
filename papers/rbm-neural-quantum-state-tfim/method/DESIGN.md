# Design
`method/run.py`: one entrypoint. Models: mean-field (N params), Jastrow (N + N(N-1)/2 params: fields a_i and one J_ij per pair i<j, no translation symmetry imposed), RBM (N + H + HN, H=alpha N). Real parameters, init N(0, 0.01^2); `--field-init c` adds c to the initial fields a_i (c=0: symmetric start S; c=0.5: symmetry-broken start B). Sampler: 256 persistent chains, Metropolis with 90% single-site and 10% global flips, 10N burn-in steps, N steps between iterations. 300 iterations, SGD p-=lr g, SR p-=lr (S+eps I)^-1 g with eps=1e-2 (main). Learning rates: `experiments/drive.py tune` + `experiments/select_lr.py` -> `experiments/lr.json` (see `experiments/PROTOCOL.md`). Final metrics: exact sums over all 2^N configurations; `energy` is the exact variational energy of the trained state. ED via scipy eigsh. J=1.
