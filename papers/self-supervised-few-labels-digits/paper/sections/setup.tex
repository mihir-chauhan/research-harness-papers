\textbf{Data and splits.} The scikit-learn digits set has 1797 images of $8\times8$ pixels (scaled to $[0,1]$). For each seed a stratified test split of 497 images is held out and never used for training or model selection; the remaining 1300 images form the unlabeled pool used for SSL pretraining and for fitting PCA. The labeled set is a class-balanced subset of the pool of $n\in\{10,50,200\}$ images (1, 5, 20 per class; tasks \texttt{n10}, \texttt{n50}, \texttt{n200}). Seeds 0--4 change the split, the labeled subset and the initialisation. The metric is test accuracy for all systems, computed identically.

\textbf{Hyper-parameters and tuning.} SimCLR and rotation: 60 epochs, batch 128, Adam (lr $10^{-3}$, weight decay $10^{-5}$), $\tau=0.5$ for SimCLR. Supervised: 300 steps, batch $\min(n,32)$, lr $10^{-3}$, weight decay $10^{-4}$. All values were fixed in advance; there was \emph{no tuning} on any split, no early stopping, and no validation set (a validation set would consume labels at $n=10$). Pretraining depends on the seed but not on the label budget, so one encoder per seed is shared by the three tasks.

\textbf{Hypotheses.} H1: SimCLR beats supervised scratch at every budget. H2: SimCLR beats rotation at every budget. H3: SSL probes beat PCA + LR at 10 labels and the gap shrinks to within two points at 200 labels. H4: removing either augmentation family lowers SimCLR accuracy at 50 labels. Statistics are paired-by-seed $t$-tests and Cohen's $d$ from \texttt{rh compare}, with five seeds, so $p$-values are indicative only.

\textbf{Compute.} CPU only (Apple M1 Pro, 2 threads per process, two processes at a time, on a shared and heavily loaded machine). A SimCLR pretraining run took on the order of two minutes, so the registry wall-clock figures are inflated by contention and are not a benchmark. All 160 runs are logged in \texttt{results/runs.jsonl}; code is in \texttt{method/run.py}. Two driver processes executed identical runs concurrently: 75 of the 90 main runs were logged twice (236 raw rows, 161 kept) with identical metrics; we kept one row per run and retained the original file (\texttt{results/runs\_raw\_with\_duplicates.jsonl}). The kept registry includes one failed sanity run (PCA + LR, exit code 1, fixed before the main runs). Total wall-clock was about 52 minutes, above the 45-minute plan, and one rotation run (seed 1, $n=50$) took 792 s under contention, above the intended 10-minute cap. Pretraining drops the last partial batch of each epoch.
