# Design
- `sindy.py`: Lorenz simulation (DOP853, rtol/atol 1e-12), library (10 monomials up to degree 2), STLSQ (columns normalised, threshold applied in original coefficient units, 10 iterations, each equation refit on its active set), derivative estimators: FD (`np.gradient`, 2nd-order), SG (`scipy.signal.savgol_filter`, polyorder 3), smoothing spline (`scipy.interpolate.make_smoothing_spline`, penalty lam), TV (Chartrand 2011 lagged-diffusivity iteration, dense, 20 iterations, eps 1e-6), weak form (200 equispaced windows, test function (1-s^2)^p, p=3, trapezoid quadrature, integration by parts).
- Derivative methods trim 5% of samples at each end; library is evaluated on the raw noisy state (flag `lib_smooth` uses the smoothed state for SG/spline). Weak form uses windows fully inside the record.
- `tune.py`: per system and noise level, grid search of the smoothing parameter and STLSQ threshold on tuning seeds 1000-1004; output `tuned.json`. Grids: SG window {11,21,41,81,161} (polyorder 3); spline lam {1e-9..1e-3}; TV alpha {1e-5..1e-1}; weak width {0.3,0.6,1,1.5,2.5}; threshold {0.05,0.1,0.2,0.4,0.6}. Selection: highest support rate, then lowest median coef_err, then the largest threshold (first version: grid order, i.e. smallest threshold; kept in `tuned_v1.json`). A tie is equal support rate and equal median error, not identical models.
- `tie_check.py`: diagnostic on the tuning seeds; repeats the tuner's grid, asserts that it reproduces `tuned.json`, and reports for each cell whether the tied configurations return identical models and what a mean-error tie-break would select (`--task lorenz_n<pct>` selects the noise level, `--out` flat metrics; per-cell records in `results/raw/tie_check_cells_n<pct>.json`).
- `run.py`: one trial; `--override` JSON overrides tuned hyperparameters for ablations. `--thr-grid a,b,c` evaluates several STLSQ thresholds on the same regression problem (diagnostic threshold grid).
