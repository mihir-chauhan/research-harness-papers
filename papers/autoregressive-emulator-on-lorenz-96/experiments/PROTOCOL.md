# Protocol
Task l96: truth is the two-scale L96 above; emulators see only X (36 values). Seeds 0-4 (seed controls all data and initialisation; seed 100 used only for the lr choice on the validation split). Metrics (identical code for every system): RMSE and ACC vs lead (anomaly relative to the training mean, pattern correlation over the 36 sites, averaged over windows), ACC lead time (first crossing of 0.6), stable_frac and survival_time (divergence = non-finite or |x|>50 in a 200 time-unit free run from 16 states), var_ratio / roughness_ratio / ks / mean_bias of surviving free runs against all test-trajectory states (first 10 time units dropped). Tuning: lr in {1e-3,3e-3} x K in {1,4}, one seed, validation split. Hardware: shared CPU laptop, 2 threads per process, <=2 processes. Groups: main (baselines, K=1,4,8), sweep_K (K=2), abl_noise (K=1 with input noise).

Note (post-hoc): the group sweep_ntrain (8x smaller training set) was added after the protocol and proposal were registered; it is an exploratory ablation, not a registered test. The tuning grid's selected lr (3e-3) is its upper edge.
