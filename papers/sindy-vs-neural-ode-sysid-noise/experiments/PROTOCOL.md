# Protocol
Tasks: pendulum, vdp; noise in {0,0.02,0.05,0.1} at N=1000 samples (main); N in {200,500,1000,2000,5000} at noise 0.05 (sweep_ntrain_*); lam sweep (sweep_lam_*); SINDy ablations (abl_sindy). Seeds 0-4 (seed controls data, noise, init). Test: 20 clean held-out trajectories (open-loop prediction from true IC); closed loop: 10 ICs (LQR, 80 steps) / first 6 (MPC, 60 steps) on the true system. Tuning: none; hyperparameters fixed a priori. Hardware: shared CPU, 2 threads. Driver: experiments/run_all.py.
MLP budget: fixed 2500 gradient steps at every N. Diagnostics: group diag_lqr (kind sanity, 3 runs) for the MLP runs whose LQR cost equals the cap. Figures and derived tables: experiments/make_figs.py (`--tables-only` leaves the figures untouched). The derived tables print recorded values with `\rhval{key}` and compute no statistic themselves; paired p-values, deltas and ratios come from `rh compare`, to be run first: `rh compare --group main --metric pred_nrmse`, `rh compare --group main --metric lqr_cost --ref "True model (oracle)"`, `rh compare --group abl_sindy --metric pred_nrmse`, `rh compare --group abl_sindy --metric lqr_cost`; main table: `rh table --group main --prec 3 --metrics pred_nrmse,support_f1,n_terms,lqr_cost,lqr_fail,mpc_cost,mpc_fail`. Hardware: Apple M1 Pro CPU, 2 threads; 453 runs in the registry (450 plus 3 diagnostic; about 7 s per MLP run, under 1 s for the others). Setup constants stated in the paper are declared in research.yaml (`rh const list`); `seconds` is the only wall-clock metric and is marked `nondeterministic: true`.
