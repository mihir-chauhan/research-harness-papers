# Design
method/run.py: data generation (RK4, dt 0.05, 40-step trajectories, 5-step input holds), SINDy-STLSQ (library: polynomials to degree 3, sin/cos x1, u; column normalised; lam 0.05; 10 iters; central differences), Neural ODE (MLP 2x64 tanh, RK4 one-step loss, Adam lr 3e-3, weight decay 1e-5, cosine decay, batch 128, fixed 2500 gradient steps at every data size, 1/7 validation split (at least 20 transitions) checked every 25 steps for model selection), DMDc (discrete least squares on [x,u]), oracle. LQR on linearisation (matrix-exponential discretisation), CEM-MPC (H=12, 48 samples, 2 iters, 8 elites). Failure = final |x|>0.5 or divergence; cost capped at 1000.
SINDy regresses the central-difference derivative on the stencil-average input (u[k-1]+u[k])/2.
Settings per system (identical for every model): pendulum train IC U[-1,1]^2, train input U[-5,5], closed-loop IC U[-0.5,0.5]^2, Q=diag(10,1), R=0.1; Van der Pol train IC U[-1.5,1.5]^2, train input U[-3,3], closed-loop IC U[-1,1]^2, Q=diag(1,1), R=0.1. Closed-loop input clip [-10,10] for both. MPC: initial sampling std 5, warm start, stage cost (x'Qx+Ru^2)dt, terminal cost x'Px dt. If the Riccati solve fails: LQR recorded as cost 1000 / fail 1, MPC terminal cost 10*Q (not triggered in the capped runs, see experiments/diag_lqr.py).
experiments/diag_lqr.py: refits a model with the functions of method/run.py and reports riccati_ok, number of capped episodes, identified vs true input gain and the true closed-loop spectral radius.
