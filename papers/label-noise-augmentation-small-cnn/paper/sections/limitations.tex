\begin{itemize}
\item \textbf{Scale.} One tiny dataset (1,078 training images of $8{\times}8$ digits), one 41k-parameter CNN, 60 epochs, 5 seeds, one train/test split. Digits are easy and redundant; with 5 seeds, $p$-values are indicative and uncorrected. Conclusions need not carry over to CIFAR-scale data or deeper networks.
\item \textbf{Noise model.} Only symmetric class-conditional noise, for which the small-loss assumption (corrupted examples have larger loss) is expected to hold comfortably; instance-dependent or asymmetric noise is not studied, nor is real annotator noise.
\item \textbf{Oracle forget rate.} The small-loss system is given the true noise rate. The comparison with CE, LS and mixup is therefore not a comparison of equally informed methods; the practical value of the rule depends on estimating $r$.
\item \textbf{Reimplementations, not reproductions.} All four systems were reimplemented in one script. The selection rule is one-network and per-batch, not two-network Co-teaching; no tuning was done for any system in the main grid, and the sweeps show that the pre-set mixup $\alpha$ and the warm-up schedule were not optimal. A tuned comparison (equal tuning budget, validation set with noisy labels) was not run.
\item \textbf{No early stopping / no validation.} We report the final epoch, which exaggerates memorisation relative to what a practitioner using early stopping on a clean validation set would see; the 5-epoch test-accuracy curves in the run logs (Table~\ref{tab:curves}) show that the ranking at final epoch is specific to final-epoch evaluation, and those checkpoint numbers are selected on the test split and therefore optimistic.
\item \textbf{Test-split sweeps.} The sensitivity sweeps are evaluated on the test split. They describe the response surface and should not be read as tuned results.
\item \textbf{Compute accounting.} Runs shared a loaded machine; median wall time per run was about 23\,s but two runs exceeded 300\,s because of contention, not because of the method.
\item \textbf{Identical behaviour at 0\%.} The small-loss system equals CE at 0\% noise by construction, so no information about its cost on clean data (where an estimated, non-zero rate would be used) is obtained.
\end{itemize}
