# Protocol
Task: (a+b) mod 23, p^2=529 pairs; random train/held-out split per seed (train fraction frac); held-out = all remaining pairs, never used for training or tuning.
Systems: uniform, operand-size curriculum, anti-curriculum, identical model/optimiser/budget/data per seed. Seeds 0-4 (main and sweeps), 0-2 (grid). Seed 100 was used only for a pilot to choose lr and the main cell.
Groups: main (wd=1, frac=0.5), grid (wd in {0,1,3} x frac in {0.4,0.5,0.7} minus the main cell), sweep_warm (T_c in 250,500,2000,4000), abl_shuffled (random order, T_c=1000).
Metric: steps_to_95, censored at 4000. Hardware: shared Apple-silicon CPU, 2 threads, two processes at once. Cost: ~0.005 s/step, <=25 s/run.
Registry note: run_all.sh logged the grid runs under group `grid` (kind ablation); in commit c0d187c these 72 rows were relabelled to group `main` and kind method/baseline (metrics and run provenance unchanged). analysis/make_tables.py reads them from `main`; results/tables/grid.md is stale from before the relabel and is superseded by grid_pivot.tex. Seeds 5 and 6 of the main cell were run in group `curves` (for Fig. 2) and are reported in the pooled 7-seed table (analysis/pooled.py, post hoc).
Tuning budget: ~10 exploratory pilot runs (seed 100, outputs not kept, not in the registry) for lr in {1e-3,3e-3}, wd in {0,1,3}, frac in {0.3,0.5,0.7} on uniform sampling; nothing tuned per system.
