# Design
`method/run.py`: one-layer pre-LN transformer (d=64, 4 heads, MLP 256, learned token+position embeddings, 3 tokens [a,b,=], readout at "="), (a+b) mod p, p=23. AdamW (lr 3e-3, betas 0.9/0.98, decoupled weight decay `wd`), batch 128 sampled with replacement from the current pool, 4000 max steps, evaluation every 25 steps on the full held-out set (all pairs not in train) and the full train set. Train fraction `frac` of the 529 pairs, random split per seed.
Samplers: uniform = whole train set. Curriculum = train pairs sorted by max(a,b) (ties random), pool = first ceil(q(t) N) pairs (at least 32), q(t)=min(1, q0+(1-q0) t/T_c), q0=0.15, T_c=1000. Anti-curriculum = same with order reversed (largest operand first). Shuffled control (`--order random`): same pacing, random order.
Metrics: steps_to_95 (first eval step with held-out acc >=0.95, run stops there; 4000 if never = censored), reached (0/1), steps_to_train95, grok_gap = steps_to_95 - steps_to_train95, final accuracies, wall_s.
No baselines from the literature are re-implemented beyond the uniform-sampling recipe of grokking studies (power2022grokking style); no hyperparameter other than lr was tuned (pilot on seed 100, uniform).
