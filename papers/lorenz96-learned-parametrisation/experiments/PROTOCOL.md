# Protocol
Tasks: F20_c10 (primary), F20_c4. Seeds 0-4 (main), 0-2 (ablations). Splits by independent trajectories (train 16 chains, val 4, test 10, reference 40; distinct seeds). All systems share data, metrics, step size (0.005), ensemble size (10), rollouts (20 x 400 t.u.). Tuning budget: none (poly degree 4, MLP 32x2, 40 epochs fixed a priori). Hardware: shared CPU, 2 threads, each run intended to stay under 6 min (two MLP runs took 394 s and 552 s of wall time under machine load). Metrics defined in proposal.md. Groups: main, floor, abl_ar1, abl_deg, abl_mlpin, abl_shift, sanity (smoke test; step-size pre-check experiments/precheck_dt.py). Forecasts: 100 initial conditions (10 per test chain).
