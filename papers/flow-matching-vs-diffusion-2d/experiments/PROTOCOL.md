# Protocol
Tasks: eight_gaussians (radius 2, std 0.1), two_moons (sklearn-style, noise 0.05, scaled x2), checkerboard (4x4 on [-2,2]^2). Training data are drawn on-line; the held-out reference is 10k points from fixed seed 12345. Seeds 0-4 for main, 0-2 for ablations; the seed fixes initialisation, training stream and sampling noise. Steps K in {1,2,4,8,16,32,64,100}, uniform grids. Metrics: SW1 (256 fixed random directions, 10k generated vs 10k held-out), biased MMD^2 with RBF bandwidths {0.1,0.3,1,3} on the first 3000 points of each set, straightness = chord/arc length of 100-step trajectories (2000 samples). "Real data" row: 10k fresh true samples against the reference (noise floor). No tuning: all hyperparameters were set once and identical for every system. Hardware: shared Mac CPU, 2 threads, each run about 3-54 s (rh run duration), about 35 minutes of wall-clock in total with two runs at a time. Tables, tests and figures are regenerated from results/runs.jsonl by `sh experiments/make_tables.sh` (rh table, method/postprocess_tables.py for labels and marks, experiments/analyze.py for the registered tests in tests.tex, the exploratory tests in expl.tex and the figures, rh compare for the per-task CSVs).
