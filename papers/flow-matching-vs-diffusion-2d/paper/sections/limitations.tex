\textbf{Scale.} Three 2D densities, one MLP (four layers of 128), 3000 updates, five seeds (three for ablations): the paired tests have four or two degrees of freedom and are uncorrected for multiplicity, so $p$ values are indicative. Nothing here transfers to images or to larger networks without further evidence. \textbf{No tuning.} Every system used the same hyper-parameters, set once; a tuned diffusion baseline (other schedules, noise-level grids, higher-order solvers, $\hat x_0$ clipping, EDM-style preconditioning~\cite{karras2022elucidating}) could close part of the gap, and the few-step diffusion deficit may be specific to the uniform timestep grid used. \textbf{Compute.} Reflow gets twice the updates of FM and 20000 pairs; we did not run an FM model trained for the same total. \textbf{Metrics.} SW with 256 fixed directions and a four-bandwidth biased MMD on 3000 points are noisy near the floor (the real-data floor is itself 0.014 to 0.022 SW), so differences among the best systems at $K\ge16$ are not resolved; the two metrics rank FM and DDIM differently at $K{=}1$ on all tasks (SW favours FM, MMD favours DDIM) and at $K{=}4$ and 16 on two moons (SW favours DDIM, MMD favours FM, nominally at 16). \textbf{Reimplementation.} All methods are our own reimplementations, not the authors' code. \textbf{Process.} A double launch of the run driver produced 88 duplicate registry rows (87 identical, one failed with empty metrics after a race on shared file paths); they were moved from \texttt{results/runs.jsonl} to a separate file, and four kept rows carry a timing measured in the sibling process. No run was dropped for its result. Mechanistic readings (the cosine failure, the teacher cap, the $K{=}1$ metric disagreement) rest on one diagnostic configuration each or on the table values only, not on dedicated interventions beyond those reported. \textbf{Solvers.} Heun was run only for the flow model; no second-order or multistep solver was run for the diffusion model, and the Heun comparison and the exploratory tests of Table~\ref{tab:tests} were not registered in advance.
