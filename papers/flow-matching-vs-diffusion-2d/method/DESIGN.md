# Design
method/run.py: one entrypoint. MLP 2+1+16 -> 4x128 SiLU -> 2. Training: on-line fresh samples, 3000 iterations, batch 512, Adam lr 2e-3 cosine to 0, EMA (0.999 with warm-up) used for sampling. Diffusion: eps-prediction, T=1000, linear betas 1e-4..0.02 (cosine for ablation), time input t/T; sampling by DDIM/eta formula on a uniform strided timestep grid, the last step goes to alpha_bar=1. FM: x_t=(1-t)z+t x, target x-z, t~U[0,1], Euler/Heun with uniform grid. Reflow: 20000 (z, ODE_100(z)) pairs from the teacher, student initialised from the teacher, same optimiser/iterations. Metrics: see PROTOCOL.md. Checkpoints cached in results/ckpt (not committed) so that sampler variants share one trained model.
