# Design
`method/run.py` is the single entrypoint. Model: decoder-only transformer, 2 pre-LN blocks, d=64, 4 heads, FF 128, GELU, learned positions, untied output head (69.4k-70.0k params). Sequence: `[task token, 8 digits, SEP, 8 output tokens]`; loss and exact-match only on the 8 output tokens (exact match = all 8 greedy tokens correct = teacher-forced argmax correct everywhere).
Tasks: sort_asc (pretraining, token 11), sort_desc (12), reverse (13). Pretraining: 4000 steps, batch 128, AdamW lr 2e-3, cosine, 20,000 fixed sequences (seed 1000+s). One pretrained model per seed, cached under results/raw/ckpt.
Adaptation (all systems identical): 2000 fixed training sequences, 1500 steps, batch 64, AdamW (wd 0), 50 warm-up steps then cosine decay; learning rate per system (tuned, see PROTOCOL.md).
Systems: `full` (all params), `lora` (frozen base, W+(alpha/r)BA on q,k,v,o,ff1,ff2 of both blocks, alpha=2r, A Kaiming-uniform, B=0), `lastblock` (last block + final LN + head), `head` (output head only), `scratch` (random init, all params, same budget), `pretrained` (no adaptation). Embeddings are frozen in LoRA/lastblock/head, so the new task token has a fixed random embedding there.
Evaluation: 2000 fresh sequences per task (test seed 5000; val seed 7000 used only for tuning). forgetting = sort_asc exact match before minus after adaptation, queried with the sort_asc token.
