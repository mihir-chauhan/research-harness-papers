\textbf{Data.} A fixed library holds up to four of the lowest distinct local minima per size, found by L-BFGS from 40 random starts per $N$: one minimum for $N{=}5$, two for $N{=}6$ and four for each $N\ge7$ (the lowest 13-atom energy found, $-44.327$, agrees with the published global minimum~\cite{wales1997global}). Each configuration has a uniformly random $N$; half are a library minimum with a random rotation plus Gaussian noise (std $\sim U[0.02,0.12]$ per coordinate), half are random points in a ball of radius $0.62N^{1/3}+0.35$ with pair distance $\ge0.85$. We resample until $E\le50$. This truncation was chosen before the main runs because the perturbed-minimum energies are heavy-tailed: in a logged check of 4000 untruncated samples, a fraction \rhval{sanity/energy-tail-untruncated/lj_clusters/perturbed_frac_above_cap/mean} of the perturbed configurations exceeds 50, with a maximum of \rhval{sanity/energy-tail-untruncated/lj_clusters/perturbed_max_energy/mean}, against a fraction \rhval{sanity/energy-tail-untruncated/lj_clusters/random_frac_above_cap/mean} and a maximum of \rhval{sanity/energy-tail-untruncated/lj_clusters/random_max_energy/mean} for the random ones. Atom order is random. The minima library is shared by train and test, so test points are not from unseen minima.

\textbf{Splits and seeds.} For seed $s$ all systems see the same $n$ training, $\max(50,\lfloor n/4\rfloor)$ validation (hyperparameter selection only) and 1000 test configurations. Main group: $n{=}500$, seeds 0--4. Learning curve: $n\in\{50,150,1500\}$, seeds 0--2 (the $n{=}500$ point uses the main runs). The three sets are drawn in sequence from one generator per seed, so for a given seed the training sets are nested across $n$ but the validation and test sets differ between sizes. Ablations: $n{=}500$, seeds 0--4 for KRR and ridge variants, seeds 0--2 for MLP variants. Test-set transforms: random rotation, random permutation, and both (fixed transform seed per run).

\textbf{Metrics.} Test energy MAE (units of $\epsilon$; the standard deviation of the test energies is between \rhval{sweep_ntrain/mean-predictor@n_train=1500/lj_clusters/test_energy_std/min} and \rhval{main/mean-predictor/lj_clusters/test_energy_std/max} over all runs), MAE per atom, MAE on perturbed and random subsets, MAE on rotated+permuted test inputs, and the invariance defect $\overline{|\hat E(g\mathbf x)-\hat E(\mathbf x)|}$, the test-set mean for one random rotation+permutation $g$ per configuration.

\textbf{Tuning budget (validation only).} For KRR we take the pair with the lowest validation MAE among 19 values of $\gamma$ ($10^{-7}$ to $10^{2}$ in half decades) and 16 values of $\lambda$ ($10^{-13}$ to $10^{2}$ in decades), identically for every descriptor. Linear ridge: the same $\lambda$ values. MLP: 3000 Adam steps (batch 64, cosine schedule), learning rate in $\{10^{-3},4\cdot10^{-3}\}$. Architecture and steps are fixed, not tuned per system; the mean predictor is untuned. The KRR grid was widened after an external audit of the first version of this study, which had used a $5\times5$ grid ($\gamma\in[10^{-2},1]$, $\lambda\in[10^{-9},10^{-1}]$); the new bounds were set from validation errors only and all KRR runs were repeated (Section~\ref{sec:ablations}).

\textbf{Hardware and runtime.} Shared CPU machine, 2 threads, PyTorch CPU, two runs at a time. The slowest KRR or ridge run took \rhval{sweep_ntrain/symfn-sum-krr/lj_clusters/runtime_s/max} s, the slowest MLP run \rhval{sweep_ntrain/sorted-dist-mlp/lj_clusters/runtime_s/max} s and the slowest atomwise run \rhval{main/symfn-atomwise-mlp-bp-style/lj_clusters/runtime_s/max} s (in-run wall-clock time, which is not reproducible; the spread within a kind is mostly machine load). The MLP runs were not repeated, since their code path did not change.

\textbf{Hypotheses (registered in \texttt{proposal.md} before the runs).} H1: both invariant descriptors beat raw coordinates at $n{=}500$ for both regressors (Welch test, 5 seeds). H2: raw-coordinate models degrade at least $2\times$ under rotation/permutation, invariant ones are unchanged (defect $<10^{-4}$). H3: SF-KRR beats sorted-distance KRR at $n\in\{50,150\}$ (Welch test, 3 seeds). H4: KRR beats the MLP of the same descriptor at $n\le150$ for the majority of descriptors, and the gap shrinks or reverses at larger $n$. All tests are two-sided Welch $t$-tests at $\alpha=0.05$ without multiple-comparison correction. \textbf{Which statistics are printed.} A $p$-value is printed only where \texttt{rh compare} recomputes it from the run registry, which it does within the main group ($n{=}500$) with SymFn-sum KRR as the reference (Table~\ref{tab:tests}). The registered tests at the other training sizes, between other pairs of systems, and between an ablation and its full model are computed by \texttt{experiments/analyze.py} and stored in \texttt{results/analysis\_stats.txt} in the repository; for these we state the outcome but print no $p$-value, and give the registry means and the per-seed ranges (smallest to largest seed value) instead.
