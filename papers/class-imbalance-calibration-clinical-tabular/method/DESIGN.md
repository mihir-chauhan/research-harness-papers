# Design
`method/run.py`: one run = one (system, model, task, seed). Data: sklearn breast cancer, positive = malignant. Stratified 70/30 split (random_state=seed), standardisation fitted on train. For 1:k, training positives subsampled to round(n_neg/k) (min 2); test rows kept, test positives weighted so the weighted prevalence is 1:k. Systems: none; reweight (balanced weights n/(2 n_c): LR class_weight, GB sample_weight); ros (duplicate to 1:1); smote (k=5 neighbours, numpy, round(ratio*n_neg) - n_pos new points, --smote_ratio default 1:1); threshold (no correction, cut-off = training prevalence). --prior_corr 1 adds log(pi/(1-pi)) - log(pi_eff/(1-pi_eff)) to the logit. Models: LR (L2, C=1, lbfgs), GB (sklearn GradientBoostingClassifier, 100 trees, depth 3, lr 0.1, no subsampling). Metrics are weighted: AUROC, AUPRC (average precision), Brier, calibration slope, CITL, sens/spec at 0.5 (threshold system: training prevalence).
