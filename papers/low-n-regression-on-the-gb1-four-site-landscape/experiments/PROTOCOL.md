# Protocol
Tasks: rand_N (train = N random variants of all 149,361; test = all others) and dbl_N (train = N random variants among the 2,168 wild-type/single/double mutants; test = all variants with Hamming distance >= 3, i.e. 147,193 variants), N in {48,96,384,2000}. Seeds 0-4 (5 draws; the draw is shared by all systems). Metrics: Spearman on the test set, top-100 recall (fraction of the 100 true best test variants among the 100 top-predicted), Spearman per Hamming distance of test variants (HD2/3/4, reported when >=100 test variants). Raw fitness is the regression target. No validation split: hyperparameters are by CV (ridge) or marginal likelihood (GP) on the training set only; the CNN configuration was chosen on a separate draw (seed 100) at rand_96 and rand_384 (group tune_cnn, 7 configs: base, epochs 100, epochs 400, dropout 0.2, weight decay 0.1, width 32, dropout 0.2 + weight decay 0.1; the last had the best mean Spearman over the two tasks) and then fixed (dropout 0.2, weight decay 0.1, 200 epochs, width 64) for all tasks. Hardware: shared CPU, 2 threads, torch CPU. Each run < 1 min.
Groups: main (4 systems x 8 tasks x 5 seeds), abl_gp (fixed GP hyper-parameters), sweep_alpha (ridge alpha grid at rand_384), abl_cnn (ensemble 5, log target).

Data URL: https://github.com/J-SNACKKB/FLIP/raw/main/splits/gb1/four_mutations_full_data.csv.zip
Note: 30 superseded rows in results/runs.jsonl labelled 'CNN (reimplemented)' actually ran --system ridge (driver naming bug); they are excluded from aggregation and the CNN rows used are the later correctly-named ones.
